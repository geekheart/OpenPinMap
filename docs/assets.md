# 示例素材与来源

| 文件 | 来源及处理 |
| --- | --- |
| `assets/s31.webp` | 用户提供的 `S31-TINY 产品图.zip` 中 `S31-TINY 正面透明底.png`；裁去透明外边距，按比例缩放至宽 1635 px，再无损编码为 WebP。原有透明通道保留。 |

示例中 `name` 为显示名称，`_pin` 为连接器针号，`_net` 为工程网络名，`_alias` 为 UART / SDIO 别名。它们不是新器件的自动推导规则。工程原文件与原理图不随网站发布。

S31 产品图片、器件商标及标识归各自权利人；本仓库不为这些素材另行授予商标或图片许可。发布的示例用于展示引脚标注流程。
