# OpenPinMap v1.2.0

[中文工作台](https://geekheart.github.io/OpenPinMap/) · [English workspace](https://geekheart.github.io/OpenPinMap/?lang=en)

## 中文

- 每组可独立选择横向 / 纵向标签排列，支持四面引脚布局。
- 文字方向独立设置，可选正常横排或逐字竖排；横向排列、横排文字加标签旋转 90° 可形成一排文字整体转向的竖直胶囊。
- 每个标签和整组均可按四个直角方向旋转，整组可关于本地 X / Y 轴镜像，包含文字字形。
- 切换排列、文字方向或标签旋转会按标签尺寸调整针距，保留净空，修复纵排竖字时相互遮盖的问题。
- 点击选择、缩放、间距手柄、对齐和引线适配旋转与镜像；Canvas、PNG、JPG 和 SVG 使用一致的几何变换。
- 保存恢复新增设置，并兼容旧版项目、生成器扩展、本机草稿、历史记录和中英文切换；离线 HTML 包含相同功能。
- 32 项单元测试和 19 项浏览器回归通过，包含纵排竖字、旋转镜像、PNG / SVG 一致性及英文离线页面。

## English

- Choose horizontal rows or vertical columns independently for each group, including pin layouts on all four sides.
- Set text direction independently to horizontal text or stacked characters. Horizontal layout, horizontal text and 90° label rotation produce a row of upright capsules with each name turned as a whole.
- Rotate individual labels or the whole group in quarter turns. Mirror groups about their local X / Y axes, including the letter shapes.
- Automatically adjust pin spacing when changing layout, text direction or label rotation, preserving clearance and fixing overlapping labels in vertical layouts with stacked text.
- Keep selection, resizing, spacing handles, alignment and leaders consistent with rotation and mirroring. Canvas, PNG, JPG and SVG share the same geometry.
- Save and restore the new settings while retaining compatibility with older projects, generator extensions, local drafts, history and language switching. The offline HTML includes the same features.
- All 32 unit tests and 19 browser regressions pass, including stacked vertical labels, rotation and mirroring, PNG / SVG consistency and the English offline page.
